# Master-s-Thesis
This is the repo for the master's thesis by Amund Godal. This repo consists of STEP-files, INO-code, and test data in form of pressure data, boolean funtionality data, and force measurement data. The data is presented in its raw form, which is the basis for plots in the thesis itself. \n 
The INO code is the code used for the entire replanting sequence. To test the individual sub-systems one could use this as a basis to separate out disired test objects.
